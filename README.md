# Selenium Automation Setup

## What was installed
- Python 3.12
- Selenium
- webdriver-manager

## Files
- requirements.txt
- selenium_demo.py

## Run
From the current folder/workspace directory:

```powershell
python selenium_demo.py
```

Or from Windows Explorer, double-click the launcher:

```text
run_selenium.cmd
```

This will open Chrome, navigate to https://www.selenium.dev/, print the page title, save the result into the current folder, and then close the browser.
